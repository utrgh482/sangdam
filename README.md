# 상담 수첩 (sangdam)

여주시농업기술센터 현장 상담 기록용 **상담 수첩** 앱입니다. (이사돔의 상담 부분을 따로 떼어 만든 선물용 앱)

- `docs/` — 앱 화면 페이지 (GitHub Pages: https://utrgh482.github.io/sangdam/). PC 에서는 이 주소를 브라우저로 열면 PC 판이 됩니다. 자료는 들어 있지 않습니다.
- `app/` — 그 페이지를 여는 안드로이드 앱(껍데기). GitHub Actions 가 apk 를 만들어 Releases 에 올립니다.

상담 내용·농가 연락처·사진은 이 저장소에도, 페이지에도 없습니다. 쓰는 사람의 핸드폰과 PC 브라우저 안에만 있고, 둘을 맞출 때는 본인 우편함(비공개 저장소)에 비밀번호로 잠근 덩어리만 잠깐 놓입니다.
